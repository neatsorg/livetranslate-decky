# LiveTranslator-kun (Windows版)

画面をキャプチャし、OCRで文字を認識して、リアルタイムで翻訳結果をオーバーレイ表示するツールです。現在は、英語から日本語への翻訳に対応しています。オリジナルはSteam Deck/Linux用で、移植版としてWindowsバージョンが存在します。

AIコーディングを使用しています。他のコードを流用した部分はないですが、気になさる方は使用をお控えいただければと思います。

[Video Demo](https://www.youtube.com/watch?v=wTeWC3wXl9k)

※作者自身が作ったWindows版のexe実行ファイルを含むパッケージは、外部サイトで配布します（下記、[ZIPファイルからインストールする場合](#ZIPファイルからインストールする場合)を参照）。ビルドの手間賃くらいの意味で有料とさせていただきます:）  
無料でお使いになりたい方は、ぜひソースからビルドしてください。

## 機能

- リアルタイム自動翻訳 - ゲーム画面上に表示された文章を自動で検出し、原文の座標に翻訳を表示します。画面内で文章の位置が変わったり、スクロールしたり、画面そのものが切り替わった場合でも、追随して翻訳を試みます。画面表示をリフレッシュして翻訳し直したり、一時的に翻訳機能を停止することもできます。
- 矩形キャプチャモード - ゲームに応じて字幕などの表示エリアのみに限定した自動翻訳ができます。
- 直近キャッシュ - 同じ文章が何度も表示される局面で、再OCRや再翻訳を行わず即時的な表示ができます。

## 拡張性

- マルチ翻訳エンジン：Google Cloud Translate、DeepL、Gemini AI、Google翻訳、Ollama使用によるAIモデル、などを選択可能。
- キーバインド：画面の更新、一時停止と再開、両方の機能を、キーボード、マウスボタン、ゲームパッドなどに割り当てられます。各キーバインドは、長押しやキー同時押しに対応。デフォルトは**F9**（単押しで更新、長押しで一時停止/再開）。

## 動作環境

- Windows 10 または Windows 11
- 翻訳元となる言語の、Windows OCRコンポーネント(このソフトの設定内からインストールできます - 下記[セットアップ](#セットアップ)参照)
- 各種ダウンロードや、クラウド翻訳エンジンを使う際のインターネット接続

## ZIPファイルからインストールする場合

1. 本ソフトの[Windowsバージョン最新版を外部サイトよりダウンロード](https://bunkei.tech/videogame-computing-20260830-705/)してください。
2. ダウンロードしたzipファイルを好きな場所に解凍してください。基本的には、どこのフォルダでもOKです。
3. 解凍したファイルの中にある`LiveTranslator-kun.exe`を実行します。警告が表示される場合については[セットアップ](#セットアップ)を参照してください。ソフトが起動すると、タスクトレイにアイコンが表示されます（デスクトップの時計の隣、または「^」の中の隠れたアイコン一覧内）。右クリックすると**設定...** やキャプチャの開始/一時停止ができます。最初は設定をするのがおすすめ。

## セットアップ

- **初回起動時のWindows SmartScreen警告**: 本ソフトウェアはコード署名をしていないため、`LiveTranslator-kun.exe`を初めて実行する際に、青い **「WindowsによってPCが保護されました」** というウィンドウが表示されることがあります。しかし別に怖いことはやっておりませんので安心してOKです。**詳細情報**と書かれた部分をクリックすると**実行**がクリック可能になるので、それを押してください。この作業は、ファイルを解凍した、最初の1回だけでOKです。
- **OCR言語コンポーネント**: 使う前に、翻訳したい外国語のOCRコンポーネントをインストールする必要があります。タスクトレイのアイコンを右クリックし、メニューから**設定...** を選択。設定画面が開いたら**OCRエンジン**の横にある**OCR言語を管理...** を押し、開いたウィンドウで、翻訳したい言語の横にある**インストール**をクリックしてください。Windows管理者権限(UAC)の確認画面が表示され、これを許可すると、しばらくしてOCR言語コンポーネントがダウンロード完了します。ネット接続の状況により、多少時間がかかることがあります。

以下は必要な場合のみ:

- **クラウドAPIキー**: Gemini AI、Google Cloud Translate、DeepLを使う場合。**設定...** の**翻訳エンジン**を切り替えると、それぞれ専用のAPIキー欄が表示され、入力することで使用できます。APIキーの発行については、各サービスのヘルプ等をご覧ください。なお、作者としては有料エンジンの中ではGoogle Cloud Translateを最もおすすめします。またデフォルトのエンジン（Google翻訳）は無料であるため、キーもアカウントも不要です。
- **Ollama**: 翻訳エンジンをOllamaに設定する場合。**URL**にローカルまたはLAN上のOllamaサーバーを指定してください。Ollamaのインストールや設定、起動についてはサポート外です。ご自身で行ってください。

## 使い方

1. このソフトは一時停止状態で起動します。タスクトレイのアイコンを右クリックし、メニューから**設定...**を選んで設定画面を起動します。
2. 設定画面の**対象ウィンドウ名**のメニューで、翻訳を行うアクティブウィンドウのタイトルを選んでください。一致するものがない場合、自分で入力する（たとえばゲーム名などを）こともできます。空欄にすると、画面全体が翻訳の対象になります。 - **一覧を更新**ボタンをクリックすると、現在開いているウィンドウ一覧を更新できます。翻訳対象ウィンドウの設定が終わったら、セーブして設定画面を閉じてください。
3. タスクトレイのメニューで**キャプチャ開始**を選ぶと一時停止が解除され、自動翻訳が始まります。自動翻訳の実行中は、タスクトレイのメニュー項目が**一時停止**に変わります。これを選ぶと自動翻訳が停止し、画面上の翻訳文字列が消えます。
4. タスクトレイのメニュー項目を選ぶ代わりに、デフォルトでは、**F9**キーの長押しで、一時停止/再開を切り替えることができます。また、**F9**キーを（長押しではなく）1回だけ押すと、リロードになります。つまり画面上の文章がもう一度走査されて、翻訳を表示し直します。
5. キーバインドの変更は、設定画面の**キーバインドを設定...**ボタンをクリックすることで行えます。
6. 自動翻訳が一時停止した状態でリロード操作を行うと、翻訳が一度だけ表示されます。常に翻訳が表示され続ける自動翻訳モードが使いにくいゲームでは、こちらのほうが便利です。
7. タスクトレイのメニューで**終了**を選ぶとソフトを終了します。一時停止とうまく使い分けてください。

### キャプチャ範囲（固定ROI）

1. 画面内の特定範囲のみを翻訳対象にしたい場合、まず設定画面で**キャプチャ範囲（固定ROI）を設定...** をクリックします。
2. 「スクリーンショットを再取得」をクリックしてスクリーンショットを表示し、**左端（Left）**/**上端（Top）**/**幅（Width）**/**高さ（Height）** を指定して、翻訳対象にしたい領域を設定します。文章の表示される位置が常に同じであるゲームや、画面全体を翻訳されるとうっとおしい、という場合に利用してください。
3. **保存して有効化**をクリックすると範囲指定での翻訳が有効になります。範囲指定での翻訳を解除するには、**固定ROIを無効化**をクリックしましょう。画面全体の文章検出に戻ります。

## トラブルシューティング

**Windowsに起動をブロックされる**
上記の[セットアップ](#セットアップ)を参照してください。SmartScreen警告画面で**詳細情報**→**実行**の順にクリックすると、起動できるはずです。

**何も検出されない・翻訳が表示されない**
- タスクトレイのアイコンを右クリックし、メニューが**キャプチャ開始**になっている場合は、一時停止中です。その項目を選択して、自動翻訳を開始してください。
- 翻訳エンジンまたはOCRエンジンが未設定の場合は、起動時にトレイ通知でその旨が表示されます。上記の[セットアップ](#セットアップ)を参照して、設定してください。
- 設定した**対象ウィンドウ名**が、実際に開いていて、かつ最前面に表示されている（アクティブな）ウィンドウになっているかどうか、または空欄（画面全体を翻訳する）状態になっているかも、確認してください。

**翻訳エンジンがAPIキーのエラーを表示する**
設定画面で、該当するキーが正しく入力されているか確認してください。Gemini、Google Cloud Translate、DeepLはそれぞれ別のキーを使用します。

**OCR言語のインストールが失敗する、またはインストール済みのはずの言語が「未インストール」と表示される**
設定画面の**OCR言語を管理...** で、該当する言語の横の**インストール**をもう一度クリックし、再ダウンロードしてください。

## Windows版の制限事項

1. フルスクリーンモードには対応していません。ウィンドウ起動したゲームでご使用ください。
2. 現在、マルチモニタには対応していません。複数のディスプレイをお使いの場合は、「1」（メインディスプレイ）上で起動したゲームを翻訳対象にしてください。別モニタ上で起動したり、別モニタに移動したウィンドウは、翻訳の検出対象にできません。
3. Linux版にあった、タップした箇所のみを翻訳する機能は存在しません。
4. 翻訳字幕が狭いエリアに複数表示される場合、まれに重なり合ってしまうことがあります。これについてはバグに近いですが、使用上の不都合が軽微なので、今のところ未修正のままにしています。

上記の制限については、Windowsバージョンを使用するユーザーがもし多ければ、対応する可能性があります。今のところは未定です;)
