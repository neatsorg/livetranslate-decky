# LiveTranslator-kun

[English](./README.md) | [日本語](./README.ja.md)

[Decky Loader](https://github.com/SteamDeckHomebrew/decky-loader) 用プラグイン。Gamescope/PipeWire経由で画面をキャプチャし、OCRで文字を認識して、リアルタイムで翻訳結果をオーバーレイ表示します。Steam Deckでのゲーム字幕翻訳を主な用途として作られていますが、多くの機能は、標準的な Linux 環境でも動作します。

[Windows Version](../)もリリースしました！

現在は、英語から日本語への翻訳に対応しています。

AIコーディングを使用しています。他のコードを流用した部分はないですが、気になさる方は使用をお控えいただければと思います。

[Video Demo](https://www.youtube.com/watch?v=wTeWC3wXl9k)

## 機能

- リアルタイム自動翻訳 - ゲーム画面上に表示された文章を自動で検出し、原文の座標に翻訳を表示します。画面内で文章の位置が変わったり、スクロールしたり、画面そのものが切り替わった場合でも、追随して翻訳を試みます。画面表示をリフレッシュして翻訳し直したり、一時的に翻訳機能を停止することもできます。
- 矩形キャプチャモード - ゲームに応じて字幕などの表示エリアのみに限定した自動翻訳ができます。
- 直近キャッシュ - 同じ文章が何度も表示される局面で、再OCRや再翻訳を行わず即時的な表示ができます。

## 拡張性

- マルチ翻訳エンジン：Google Cloud Translate、DeepL、Gemini AI、Google翻訳、Ollama使用によるAIモデル、などを選択可能。
- キーバインド：画面の更新、一時停止と再開、両方の機能を、キーボード、マウスボタン、ゲームパッドなどに割り当てられます。各キーバインドは、長押しやキー同時押しに対応。デフォルトは**F9**(単押しで更新、長押しで一時停止/再開)。

## 動作環境

- Windows 10 または Windows 11
- 翻訳元となる言語の、Windows OCRコンポーネント(このソフトの設定内からインストールできます - 下記[セットアップ](#セットアップ)参照)
- 各種ダウンロード、クラウド翻訳エンジンを使う場合のインターネット接続

## ZIPファイルからのインストール

1. 本ソフトのWindows版最新版をダウンロードしてください。
2. zipファイルを好きな場所に解凍してください。基本的には、どこのフォルダでもOKです。
3. 解凍したファイルの中にある`LiveTranslator-kun.exe`を実行します。するとタスクトレイにアイコンが表示されます(デスクトップの時計の隣、または「^」の中の隠れたアイコン一覧内)。右クリックすると**設定...**やキャプチャの開始/一時停止ができます。最初は設定をするのがおすすめ。

## セットアップ

- **初回起動時のWindows SmartScreen警告**: 本ソフトウェアはコード署名をしていないため、`LiveTranslator-kun.exe`を初めて実行する際に、青い **「WindowsによってPCが保護されました」** というウィンドウが表示されることがあります。しかし別に怖いことはやっておりませんので安心してOKです。**詳細情報**と書かれた部分をクリックすると**実行**がクリック可能になるので、それを押してください。この作業は、ファイルを解凍した、最初の1回だけでOKです。
- **OCR言語コンポーネント**: 使う前に、翻訳したい外国語のOCRコンポーネントをインストールする必要があります。タスクトレイのアイコンを右クリックし、メニューから**設定...** を選択。設定画面が開いたら**OCRエンジン**の横にある**OCR言語を管理...** を押し、開いたウィンドウで、翻訳したい言語の横にある**インストール**をクリックしてください。Windows管理者権限(UAC)の確認画面が表示され、これを許可すると、しばらくしてOCR言語コンポーネントがダウンロード完了します。ネット接続の状況により、多少時間がかかることがあります。

以下は必要な場合のみ:

- **クラウドAPIキー**: Gemini AI、Google Cloud Translate、DeepLを使う場合。**設定...**の**翻訳エンジン**を切り替えると、それぞれ専用のAPIキー欄が表示されます。デフォルトのエンジン(Google翻訳)はキーもアカウントも不要です。なお、作者としては有料エンジンの中ではGoogle Cloud Translateを最もおすすめします。
- **Ollama**: 翻訳エンジンをOllamaに設定する場合。**URL**にローカルまたはLAN上のOllamaサーバーを指定してください。アプリ自体はOllamaのインストールや起動は行いません。

## 使い方

1. タスクトレイのアイコンを右クリックし、**キャプチャ開始**を選ぶと自動翻訳が始まります。アプリは一時停止状態で起動するため、これを押す(または下記のキーバインドを使う)まで何も起こりません。実行中は同じメニュー項目が**一時停止**に変わるので、止めるときも同じ場所から操作できます。
2. デフォルトのキーバインドは**F9**です。タップで画面を更新(再検出)、長押しで一時停止/再開が切り替わります。これはトレイメニューの項目と同じ動作です。
3. キーバインドの変更は、**設定...**の**キーバインドを設定...**から行えます。
4. 設定の**対象ウィンドウ名**を空欄にすると画面全体をキャプチャします。ウィンドウ名の一部(ゲーム名など)を入力すると、そのウィンドウだけに限定してキャプチャします - **一覧を更新**ボタンで現在開いているウィンドウから選べます。
5. トレイメニューの**終了**を選ぶとアプリを終了します。このツールはゲーム画面かどうかを判断して翻訳を表示するわけではないので、翻訳が不要な状況では一時停止するか終了しましょう。

### キャプチャ範囲(固定ROI)

1. **設定...** で**キャプチャ範囲(固定ROI)を設定...** を押します。
2. スクリーンショットのプレビューを取得し、**左端(Left)**/**上端(Top)**/**幅(Width)**/**高さ(Height)** を指定して追跡したい領域を設定します。文章の表示される位置が常に同じであるゲームや、画面全体を翻訳されるとうっとおしい、という場合に利用してください。
3. **保存して有効化**を押すと有効になり、**固定ROIを無効化**を押すと画面全体の検出に戻ります。

## トラブルシューティング

**Windowsに実行をブロックされる**
上記の[セットアップ](#セットアップ)を参照してください。SmartScreen警告画面で**詳細情報**→**実行**を押してください。

**何も検出されない・翻訳が表示されない**
タスクトレイのアイコンを右クリックし、メニューが**キャプチャ開始**になっていれば現在一時停止中です。選択して開始してください。翻訳エンジンまたはOCRエンジンが未設定の場合、起動時にトレイ通知でその旨が表示されます - **設定...** から設定してください。また設定の**対象ウィンドウ名**が、実際に開いていて最小化されていないウィンドウと一致しているか、または空欄(画面全体をキャプチャ)になっているかも確認してください。

**翻訳エンジンがAPIキーのエラーを表示する**
**設定...** に、該当プロバイダのキーが正しくコピーされているか確認してください。Gemini、Google Cloud Translate、DeepLはそれぞれ別のキーを使用します。

**OCR言語のインストールが失敗する、またはインストール済みのはずの言語が「未インストール」と表示される**
設定画面の**OCR言語を管理...** で、該当する言語の横の**インストール**をもう一度押し、再ダウンロードしてください。

## もし開発が継続した場合に追加する機能

- **ゲームを一時停止＆矩形選択範囲を翻訳**：ある意味、先祖返り的な機能。めざせPCOT
- **多言語対応**：日->英の翻訳のほか、ソース言語とターゲット言語を増やす
- **Windowsへの移植**：ゲームやるならLinuxじゃんと思う派なので優先度は低いですが、Windows.Media.Ocrはすごいので。
- **ゲーム以外への対応**：わりとできそう。でも動画字幕をライブ翻訳する等は今の速度だと無理です。

## ありそうな質問と答え

- **xxxxxというゲームに対応してほしい**：個別対応するソフトではないので、無理です。別ゲームでも同種のケースが多い、という場合には対応する可能性があります。
- **翻訳が弱い**：このツールは現状、OCRと翻訳をすべて外部に投げています。なので、そいつらが強くなるのを待とう。
- **翻訳が遅い**：高速化にはまだ余地があると思います。これは、もし開発が継続するなら、やる可能性が高いです。
- **Macに移植してほしい**：有益さが相対的に小さく、関心が持てないです。
- **音声を翻訳してほしい**：負荷が大きいのであまり関心が持てないです。強力な外部APIなどがあればやってみたいかも。
- **動かない**：ご使用の環境やゲームや状況をすごく詳細に説明していただければ
わかるかもしれませんが、保証はできません。また、あなたの環境が特殊すぎると対応はさらに難しいです。
